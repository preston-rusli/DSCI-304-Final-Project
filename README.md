# Ultramarathon Insights: Demographic Patterns and Performance Evolution
A study of ultramarathon trends based on collection of ultramarathon race records registered between 1789 and 2022.

Final project for DSCI 304 -- Effective Data Visualization at Rice University.

[Project website](https://sites.google.com/rice.edu/preston-rusli-ultramarathon/home?pli=1)
